# A-1 / A-2 公式過去問モードの出典

出典：独立行政法人情報処理推進機構（IPA）

## A-1

対象：2021〜2025年の **応用情報技術者試験（AP）午前**。

- 春期・秋期の10回分
- 各回80問
- 合計800問

問題本文・選択肢・図表はアプリへ複製せず、IPA公式PDFを参照して解答します。
アプリ内には問番号、正解、分野、学習履歴、公式PDF URLを保持します。

問題ごとの詳しい解説は「応用情報技術者試験.com」の該当問題ページへのリンクを利用し、解説本文そのものは転載しません。
