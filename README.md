# ST A-1 / A-2 Trainer V4.0

ITストラテジストの科目A-1 / A-2を、IPA公式過去問PDFを参照しながら学習する個人用Webアプリです。

## V4.0 追加機能

- **A-2（旧 午前Ⅱ）を2021〜2025年度の5年分・125問追加**
- A-1は従来どおり2021〜2025年度の5年分・150問
- 公式過去問は **合計275問**
- A-1 / A-2それぞれで正答率・要復習・弱点TOP3を独立集計
- A-2にも年度横断の「今日のおすすめ10問」を追加
- A-2の「間違えた／迷った／知らなかった」別復習に対応
- A-2の弱点分野指定復習に対応
- 2021〜2025年度すべて、問題本文・図表はIPA公式PDFをアプリ内表示
- PDFページ送りを各年度・各問に合わせて設定
- Google認証、Supabase同期、RLSは既存構成をそのまま利用

## 更新方法

V3.5のファイルをV4.0で上書きし、GitHubへpushしてください。

```bash
git add .
git commit -m "Add A2 official exams and review"
git push
```

### Supabase側の変更

**追加SQLは不要です。**

既存の以下をそのまま利用します。

- `study_attempts`
- `study_bookmarks`
- `study_custom_questions`

A-2の問題IDは `a2-2025-q01` のようにA-1と分離しているため、同じテーブル内でも履歴は混ざりません。

### 環境変数

変更ありません。

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

Secret Keyはクライアント側では使用しません。

## 学習のおすすめ順

A-2はITストラテジスト固有領域なので、現在の時期はA-1より優先度を上げて使う想定です。

1. 2025年度A-2 25問
2. 2024年度A-2 25問
3. 「A-2 今日のおすすめ10問」
4. 間違えた／知らなかった問題を年度横断で復習
5. 2023〜2021年度へ拡張
6. A-1は弱点維持・模試用途で並行

## 公式PDFの扱い

問題本文、選択肢、図表はアプリ内へ複製せず、IPA公式PDFを `/api/official-pdf` 経由で表示します。アプリ側には以下を保持します。

- 年度・問番号
- 正解
- 分野・小分野
- PDFページ番号
- オリジナルの復習ポイント
- 学習履歴・自信度

PDFが端末内で表示できない場合は、画面上の「PDFを別タブで開く」からIPA公式PDFを直接参照できます。
