# ST Trainer V4.1

ITストラテジストの **A-1 / A-2 / B-1** を、IPA公式過去問PDFを参照しながら学習する個人用Webアプリです。

## V4.1 追加機能

### A-2重点ダッシュボード

- A-2の現在正答率から学習目安を表示
- 2021〜2025年度125問の **頻出領域** を件数順に表示
- 頻出領域ボタンから、その領域だけ年度横断復習
- 従来の「今日のおすすめ10問」「誤答／迷った／知らなかった」「弱点TOP3」は継続

※「学習目安」はアプリ独自の学習用目安で、IPA公式の合否判定そのものではありません。

### B-1記述トレーナー

まず **2025年度・2024年度** を収録しました。

- 各年度3問（合計6問）
- IPA公式問題PDFをアプリ内表示
- 問1 / 問2 / 問3を切替
- 1問45分のカウントダウンタイマー
- 設問別の自答案・メモ入力
- IPA公式解答例をアプリ内表示
- IPA公式採点講評をアプリ内表示
- 自己評価
  - ○ 要点を押さえた
  - △ 一部不足
  - × 書き直し
- 解答例・採点講評からの気づきを保存
- Googleアカウント単位でSupabaseへ同期

2026年度のB-1は **90分・記述式・3問中2問選択** のため、アプリでは1問45分を練習目安にしています。

## V4.0 → V4.1 更新手順

### 1. SupabaseへB-1保存テーブルを追加

Supabase Dashboard → **SQL Editor** で、次のファイルを1回実行してください。

```text
supabase/setup_v4_1.sql
```

既存のA-1 / A-2テーブルは変更しません。

追加されるテーブル：

```text
study_b1_practices
```

RLSにより、ログインした本人の答案だけ読み書きできます。

### 2. V4.1のファイルで上書き

```bash
git add .
git commit -m "Add A2 focus dashboard and B1 trainer"
git push
```

Vercelの既存環境変数は変更不要です。

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

Secret Keyはクライアント側では使用しません。

## B-1の使い方

1. ホームの **B-1 記述トレーナーを開く**
2. 年度・問番号を選ぶ
3. 45分タイマーを開始
4. 左のIPA公式問題PDFを読み、自分の答案を入力
5. 「答案を保存」
6. 「公式解答例と比較」
7. 「採点講評を見る」
8. 自己評価と気づきを記録して再保存

B-1では、単なる用語知識よりも以下を意識する設計です。

- 設問が求める **主語** を外さない
- 本文にある **根拠** を使う
- 顧客ニーズ / 企業の狙い / 課題 / 施策を混同しない
- IT施策が事業・業務課題の解決へどうつながるかを書く

## 公式PDF

問題本文・図表はアプリへ複製せず、IPA公式PDFを `/api/official-pdf` 経由で表示します。

V4.1ではB-1についても次を同一オリジン経由で表示します。

- 問題冊子
- 解答例
- 採点講評

表示できない端末では「公式PDF ↗」「別タブ ↗」からIPA公式を直接開けます。
