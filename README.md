# ST Trainer V4.6 — A-1を応用情報午前5年分へ刷新

ITストラテジスト 2026 対策用の個人学習アプリです。

## V4.6の重要変更

A-1対策を、従来の「高度試験 午前I 2021〜2025年・150問」から、**応用情報技術者試験（AP）の午前過去5年分**へ切り替えました。

対象は2021〜2025年の春期・秋期です。

- 10回分 × 80問 = **800問**
- IPA公式問題PDFをアプリ内表示
- IPA公式解答を登録済み
- Googleログイン / Supabase学習履歴同期
- 誤答・迷った・知らなかった問題の年度横断復習
- 「今日のおすすめ10問」は800問から自動選定
- 問題別の詳しい解説は「応用情報技術者試験.com」の該当問題ページを直接開く

問題別解説は転載せず、外部の解説ページへリンクします。

| 科目 | 内容 | 問題数 |
|---|---|---:|
| A-1 | 応用情報 午前 2021〜2025年 春・秋10回 | 800 |
| A-2 | ITストラテジスト 午前II 2021〜2025年 | 125 |
| B-1 | ITストラテジスト 午後I 2024〜2025年 | 6 |

A系公式問題は合計 **925問** です。

## A-1の使い方

### 1. まず年度セットを1回解く

ホームの「A-1 応用情報 午前・過去5年」から、例えば **R7秋 応用情報 午前80問** を開きます。

公式PDFは同じ位置を維持するため、PDFを順番にスクロールしながら右側で問番号ごとの解答・自信度を記録してください。

### 2. その後は「今日のおすすめ10問」

次の順に優先して出題します。

1. 間違えた問題
2. 「知らなかった」問題
3. 「迷った」問題
4. 弱点分野

### 3. 解説を確認

回答後は、正解と学習履歴を表示し、問題ごとの「詳しい問題別解説」から外部解説ページを開けます。

計算問題・論理問題では、正答根拠や途中式、他の選択肢が違う理由まで確認できます。

## 更新手順

現在のプロジェクトをV4.6の内容で上書きしてGitHubへ反映してください。

```bash
git add .
git commit -m "Rebuild A1 with AP past five years"
git push
```

Vercelの既存環境変数はそのまま利用します。

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

Secret Keyはクライアント側では使用しません。
